📊 Projeto Pandas: Análise e Manipulação de Dados

Este repositório contém um projeto prático desenvolvido para demonstrar a aplicação de técnicas de **Análise Exploratória de Dados (EDA)**, **limpeza** e **tratamento de dados** utilizando a biblioteca **Pandas** em Python.

---

## 🎯 Objetivos do Projeto
* Realizar a leitura, importação e estrutura primária de dados.
* Aplicar rotinas de limpeza (tratamento de valores nulos, duplicatas e tipos de dados).
* Executar filtragens, agregações e transformações de colunas para extração de métricas.
* Explorar padrões e insights contidos nos dados analisados.

---

## 🛠️ Tecnologias e Ferramentas
* **Python 3.x**
* **Pandas**: Manipulação, estruturação e análise de dados
* **Jupyter Notebook / Google Colab**: Ambiente interativo de desenvolvimento
